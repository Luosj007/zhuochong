# 桌宠 (Desktop Pet)

把任意一张图片变成能在桌面上爬来爬去的桌宠，可用鼠标随意拖拽。

```
tools/
├── desktop_pet.py          # 桌宠主程序
├── make_assets.py          # 抠图 + 素材管理
├── 启动桌宠.bat             # 双击启动
├── README.md               # 本文档
├── pets/                   # ← 所有桌宠素材原图放这里
│   ├── dog.jpg
│   ├── xw.jpg
│   ├── ...
└── assets/                 # (自动生成)
    ├── pet.png             # 当前使用的透明背景素材
    └── preview.png         # 蓝底预览, 检查抠图效果
```

## 快速开始

- **启动**：双击 `启动桌宠.bat`，或命令行运行 `python desktop_pet.py`
- **关闭**：右键点击桌宠 → **退出**。
  （桌宠不见了又关不掉：任务管理器结束对应的 `python`/`pythonw` 进程）

## 玩法

| 操作 | 效果 |
| --- | --- |
| 按住拖动 | 随意拖到桌面任何位置 |
| 半空中松手 | 桌宠"啪叽"掉落到地面 |
| 拖到屏幕左/右边缘松手 | 沿边缘向上爬，爬到顶会掉下来 |
| 快速点一下 | 拍它一下，它会蹦起来扑腾 |
| 滚轮 / 双击 | 调大调小 |
| 右键 | 菜单：暂停、回到地面、大小、退出 |

平时桌宠会沿桌面底部（任务栏上方）来回爬行，偶尔停下张望。

## 更换桌宠形象（三步）

1. **放图片** —— 把新图片放入 `pets/` 文件夹（支持 jpg / jpeg / png / bmp / webp）。
   可以随意命名，比如 `my_cat.png`、`anime_girl.jpg`，想加多少张就加多少张。

2. **抠图** —— 在本文件夹打开终端（地址栏输入 `cmd` 回车），运行：
   ```
   python make_assets.py
   ```
   脚本会列出 `pets/` 里所有图片及其大小，例如：
   ```
   ═══ 桌宠图片素材 ═════════════════════════════════
     [0] dog.jpg                          22.2 KB
     [1] xw.jpg                           208.0 KB
   ═════════════════════════════════════════════════
   最新图片: xw.png
   
   请输入图片编号或名称 (直接回车选最新):
   ```
   - **按编号选**：输入数字（如 `0`）回车
   - **按名字选**：输入文件名（如 `dog.jpg`）回车，支持模糊匹配
   - **直接回车**：自动选择最新添加的那张

   抠图完成后会生成 `assets/pet.png` 和蓝底预览 `assets/preview.png`（建议打开检查边缘是否干净）。

3. **重启桌宠** —— 右键旧桌宠「退出」，再双击 `启动桌宠.bat`。

> **抠图策略**：
> - 纯色背景（纯黑/纯白等立绘）→ 又快又干净，角色内部暗部不丢失
> - 复杂背景 → 优先 rembg AI 抠图（需 `pip install rembg onnxruntime`，首次自动下载模型约 170MB）
> - rembg 不可用 → 退回本地颜色分割
>
> **提示**：人物/动物"全身立绘"效果最好，主体尽量占满画面、背景越干净越好。

## 文件说明

| 文件/目录 | 作用 |
| --- | --- |
| `desktop_pet.py` | 桌宠主程序（Python + tkinter 透明窗口实现） |
| `make_assets.py` | 抠图脚本：列出素材、选择图片、生成透明背景 `assets/pet.png` |
| `启动桌宠.bat` | 双击启动桌宠 |
| `pets/` | **把所有想用作桌宠的图片都放这里** |
| `assets/pet.png` | 桌宠实际使用的透明背景素材（自动生成） |
| `assets/preview.png` | 每次抠图后的蓝底预览，用于检查效果（自动生成） |

## 环境依赖

- Python 3.x
- 运行桌宠必需：`pip install pillow`
- 抠图脚本基础能力：numpy / scipy / scikit-image / Pillow（Anaconda 环境一般已装好）
- 复杂背景 AI 抠图（可选）：`pip install rembg onnxruntime`
